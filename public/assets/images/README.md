# Imágenes de la aplicación

Coloca en esta carpeta los recursos visuales utilizados por el juego, por ejemplo:

- Logotipo del negocio.
- Fondos e ilustraciones.
- Imágenes de premios.
- Iconos personalizados.

Formatos recomendados: `webp`, `png` y `svg`.

En Angular se pueden utilizar con rutas como:

```html
<img src="assets/images/logo.webp" alt="Logo del negocio" />
```

Usa nombres de archivo en minúsculas, sin espacios ni caracteres especiales; por ejemplo, `logo-negocio.webp`.
